WORKPLACE COMMITMENT CLASSIFICATION — VERIFIED PROJECT REFERENCE
Recorded: 16 October 2026. Current deployed checkpoint: V4 (95.83% on 96 authored test examples).

1. PURPOSE AND INPUT
Classify the target employee's commitment to workplace work using the preceding conversation and the employee's target reply. This is four-class supervised NLP classification, not a generative chatbot, task executor, lie detector or judgement of actual future completion.
One dataset row contains conversation context, target employee reply, intended label and metadata. A conversation may contain several turns. Rows are not books or tokens.
Exact model input:
[CONTEXT] {context} [TARGET SPEAKER] employee [TARGET UTTERANCE] {reply}
Label/group/split/rationale columns are not included in the model input.

2. LABEL POLICY
0 NO_COMMITMENT: no new work undertaking; includes complete refusal, factual information, completed past work, another person's promise and merely social agreement.
1 LATENT_COMMITMENT: live ownership inferred from relevant ongoing action or preparation in response to a request, without direct acceptance wording.
2 QUALIFIED_COMMITMENT: actual undertaking limited by an unresolved condition, uncertainty, or partial scope. Refusing the rest does not cancel a partial acceptance.
3 EXPLICIT_COMMITMENT: direct unqualified acceptance/promise of the requested work. A prerequisite already satisfied is not an unresolved condition.
These are provisional project definitions. Availability and bare acknowledgements can admit multiple reasonable interpretations. V4 often misclassifies those cases with high confidence.

6. SPLITS, LEAKAGE AND LIMITATIONS
Fresh validation and final test were frozen before V4training. Validation alone chose checkpoint/configuration. No final-test-driven edits to model/data/labels/thresholds were made in that completed experiment. All96test rows retained. Exact normalized input/context/target/group overlap across V4splits was zero; checked prior CSVdata also had zero exact overlaps with fresh validation/test. Context pairs stayed together in one split. Input provenance was asserted; labels and group IDs were excluded.
These checks DO NOT prove no semantic similarity, template shortcuts, single-author style or pretraining contamination. Data is fictional and agent-authored; labels are provisional, not independently reviewed human gold. Only96fresh test cases. Later user manual examples exposed errors on availability, acknowledgements and preparatory requests. 95.83%is specific to the saved test, not established real-world accuracy or production readiness. Softmax scores are uncalibrated and can be very high on mistakes. Old V3test is training for V4and cannot be reported as unseen V4test. Context sensitivity is evidence of using context, not proof of correct reasoning in every case.

10. SAFE PROJECT DESCRIPTION
This project fine-tunes DeBERTa-v3-base to classify workplace commitment from conversation context and a target employee reply into four categories. The final checkpoint follows synthetic context-dependent training and two workplace adaptation stages. On a frozen96-example,balanced,fictional workplace test it achieved95.83%accuracy and95.87%macro-F1,with14/16context pairs entirely correct. Exact-overlap audits,lexical baselines and context perturbations were included. Ambiguous-language errors and the small agent-authored evaluation limit generalization claims.
